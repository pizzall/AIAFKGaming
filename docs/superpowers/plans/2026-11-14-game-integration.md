# Account, Economy, Idle and Gym Integration Plan

> **For agentic workers:** Use superpowers:executing-plans inline. User has authorized integration and local test commands.

**Goal:** 提供可注册登录、持久化养成、资源收支、请求式挂机结算和真实道馆挑战的 H5 测试版本。

**Architecture:** 在现有后端加入 SQLite 事务存储、GameService 和 HTTP 路由。复用已验证的战斗引擎、工作线程与快照。玩家活动按结束时间/游标结算，无逐玩家定时器；测试时钟只推进当前账号。

**Tech Stack:** Node.js 24、内置 SQLite、TypeScript、现有 Showdown、原生 H5。

**Spec:** architecture-design.md 与用户本轮“账号经济、完整挂机、道馆接入，并提供加资源和加速指令”的要求。

## Global Constraints

- 实际等级、六只全员双打、仅 Mega、隐藏对手赛前名单、NPC 开战随机预设。
- 道馆防守是固定快照，获胜接任；同席位串行挑战；赛季只刷新席位。
- 账号、库存、成员和结算结果持久化；资源发放与结算游标同事务，不重复领奖。
- 测试数值单独标为 testOnly，不冒充最终平衡；原作资料有的数据直接复用。
- 测试指令仅显式 --test-mode 开启，登录后作用于当前账号；赛季指令明确为全服操作。
- 继续保留旧视觉 Demo 和战斗验证入口；AI 分析不在本轮。
- 无 Git 仓库，原地工作，不新增外部服务。

- 修改 server.ts、battle/runner.ts、worker.ts：接入真实账号队伍、固定防守和比赛结果事务。
- 新增 tests/game*.test.ts：持久化、时间等价、经济、权限、加速和道馆结果验收。

## Review Focus

- 不允许未登录或跨账号读取战报/修改资源；测试接口在普通启动关闭。
- 同一命令重试不重复扣发；数据库失败回滚整个变更。
- 离线一次/分段结算等价，恢复和稀有时段按事件时间。
- 进行中的道馆挑战不会读取后来修改的队伍；失败或进程中断释放席位锁，不判玩家消极。
- 加速不会改变真实会话有效期、其他账号时钟或直接伪造胜负。

## Ledger

已实施本轮清单。本轮使用显式测试档解决未定平衡参数；这些值只为联调可玩，不替代原数据账本。

- 数据：SQLite 保存账号、会话、玩家文档、世界席位、回执、账本和比赛。复用原作数据、经验曲线、效果 mod、报名快照和两个战斗工作线程，没有增加外部服务。
- 经济：扣发与回执同事务；重要商品按当前账号小时限购；普通探索持物真实消耗，高级比赛隔离快照。未定数值移入独立测试配置。
- 时间：每次最多120次遭遇，保留后续游标；加速仅当前账号，实际会话有效期不变。一次/分次结算比较含随机状态、捕获、失败、PP与经验。
- 评审：修复匿名实验接口访问账号战报、持物消耗未写回、快结绕过PP/自爆等成本、单页及跨标签页切换账号残留旧战报；浏览器分别复现并验证清理。原规则校验保持启用，八馆两模板均可合法报名。
- 浏览器：实际注册账号；并行两小时后产矿8、果树缓存9、两只孵化完成，探索38胜/2次恢复；购买重要持物、出售矿石、收获树果、真实击败第二馆并接任；刷新/切换后资源与34只伙伴保留，零控制台错误。
- 范围：普通战斗当前同步有界执行；正式经济、8–9天满级节奏、历史挂机配置迁移未校准。AI、联赛、交换、完整技能机学习和特殊条件进化不在本轮实现。
- 最终验证：`npm.cmd test` 21/21；`npm.cmd run typecheck` 与 `node --check web/game/app.js` 无错误。手动切季恢复八馆NPC供后续测试，保留账号资产；本地8787以测试模式运行。
