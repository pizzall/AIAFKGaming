# 中文界面、多预设与心愿搜索

授权：用户要求功能H5所有玩家可见英文改为中文；多个队伍预设；工作、配对、孵化主理人等占用阻止备战/探索，备战成员不可工作；心愿单按编号/名字搜索添加。用户已确认保存预设不占用、进入备战后锁定，探索可使用该备战队。

沿用原生H5、TypeScript/SQLite及现有命令/事务，不新增服务或后台计时。

## 文件与结构

- 新增 `src/game/localization.ts`：从本地CSV建立中文名词表和操作标签；不改变引擎的稳定标识或战斗计算。
- 修改 `catalog.ts`：提供只含公开资料的物种搜索目录；读取现有species/default variants，不新增持久化目录。
- 修改 `types.ts/service.ts/idle.ts`：玩家增加可选presets（id/名称/成员/战术）及readyPresetId；旧单队伍迁移为默认预设。已有team/tactic继续表达当前队伍与战术，备战时从指定预设固定并禁止编辑该预设/当前队伍，直到取消。后台比赛由现有SQL记录判断，进行中不能取消/替换备战，出战成员不能再探索；不新增重复锁表。
- presets保存不占用；准备检查其它实际占用；工作/配对/主理人检查备战；探索允许使用已备战成员但阻止其它占用；道馆要求先备战且所有成员未在探索/工作等活动。防守存档仍不占用真实个体。
- 修改 `routes.ts`：已登录公开目录查询，状态返回可读占用/中文名词；命令增预设保存/删除、备战/取消；继续原有幂等和归属检查。
- 新增 `web/game/display.js`：中文名词与战报显示转换，消费公开字典，不导入引擎。
- 修改 `web/game/app.js/index.html/styles.css`：中文标题/属性/性格/特性/招式/道具/状态/日志；多预设编辑与备战按钮；心愿单即时搜索结果、选中卡片、添加/删除/保存与去重；探索可从保存预设选择出发。
- 本地测试指令增加中文别名并保留旧指令兼容，UI示例与帮助用中文；用户自己输入的名称不自动翻译。
- 新增边界测试：多预设保存与重开、旧档迁移、双向活动占用、比赛期间解锁限制、中文目录覆盖与编号/名字搜索、战报中文渲染；修改道馆测试明确先备战。

预设数量上限作为联调用配置设为10套，每套1–6成员、战术500字；保存可包含正工作的成员，真正备战/出发时校验并解释占用。编辑与保存其它预设不改变已经备战的队伍。

- 同一审阅者完成计划及实现复核：持久锁、旧team入口、SQL pending与多预设隔离无Important。发现中文动作被二次当成英文key翻译、预设名money被资源替换误改；先补失败回归，再限定结构化旧字段汉化，已有中文和用户名称保留。

- 测试目录与显示函数拆为 `display.js`，配套 `.d.ts` 只为TS测试提供浏览器模块签名，不引入新共享状态或框架。
- 允许非参赛的空闲伙伴在比赛期间探索，实际出战者仍受锁定；保持既有并行原则。取消备战不清空正在探索的队伍。
