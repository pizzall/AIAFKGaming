# H5 视觉与探索恢复调整

用户授权：保持红白、GBA/DS 像素风，美化功能 H5 并生成模块图标；探索只持久化 HP，不用 PP/异常状态作为挂机门槛。恢复仅作用于本次探索队，耗时为20分钟上限乘总缺失HP比例，满血无需等待。

实施方式：沿用原生H5、TypeScript/Node、SQLite和现有战斗引擎；执行 writing-plans / executing-plans 工作流，恢复规则先测试后实现，视觉用浏览器走查。

本轮改动：

- `web/game/`：保留现有账号与操作，增加模块导航图标、页首主题、总览场景、资源和设施图标、状态卡与信息层级，所有数值仍来自后端。
- `web/game/art/`：保存内置 imagegen 生成的两个16格图标 atlas（32个图标）和场景图，CSS 定位使用；不增加运行依赖。
- `src/game/idle.ts`：复用现有战斗与时间游标，每场探索以完整 PP/空异常开始，结束仅保存 HP 与实际资源消耗；恢复截止时间按 HP 比例计算，实际耗时进入日志统计。
- `src/game/service.ts`：复用 rest 命令和 centerUntil。满血直接返回且不停止探索；活动队恢复后继续原路线；无活动队时恢复当前预设队，固化参与者，避免改队后恢复错人。
- `src/game/types.ts`：只新增可选 `centerTeam`，表示当前中心恢复的固定成员，完成后清空；旧存档以当时预设队兼容。探索继续复用原有 recoveryUntil，不增加后台任务。
- `tests/game-idle.test.ts` 与恢复测试：验证PP/异常不跨遭遇、HP和真实持物仍保留，满血不等待、半血10分钟、全倒20分钟、改队不改变恢复成员、恢复后路线续行、一次/分次补结算等价。
- README 与架构当前实现记录更新，不改原纯视觉 Demo。

验收：全量测试、类型/语法检查；浏览器检查1920×1080各模块、资源操作、动态恢复、无图片缺失和横向溢出。保留测试服务运行。
