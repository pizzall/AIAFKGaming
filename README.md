# 宝可梦 AFK

当前 H5 已接入账号、持久化资产、请求式挂机结算和真实道馆挑战。前端通过 HTTP 提交操作，后端负责资源与胜负计算；原 11 页纯视觉 Demo 单独保留。

## 启动

需要 Node.js 24、Python 3.12+。依赖版本固定在 package-lock.json；战斗源码使用已有本地归档并校验 SHA-256，不另外下载浮动版本。

```powershell
npm.cmd ci
node scripts/prepare-engine.mjs
node scripts/export-effects.ts
npm.cmd run start:test
```

打开 [游戏入口](http://127.0.0.1:8787/)，注册自己的本地测试账号。默认仅绑定本机；可通过 PORT 环境变量改变端口。前后端使用独立文件和 HTTP JSON 协议，当前同源托管便于本地检查。`npm.cmd start` 关闭测试指令；两种启动方式当前都使用明确标注的联调配置。

本机若 npm 的 PowerShell shim 路径异常，可使用：

```powershell
node 'C:/Program Files/nodejs/node_modules/npm/bin/npm-cli.js' ci
```

## 已完成

- 注册、登录、退出和账号隔离；密码加盐哈希、HttpOnly 会话，存档位于 `.runtime/battles/game.sqlite`。重启服务和关闭浏览器均保留存档。
- 多套编队预设（联调上限10套），每套独立名称、1–6位成员和500字战术；保存不占用，进入备战后锁定成员。工作、配对、孵化主理人、恢复和备战相互校验；同一备战队可探索，比赛期间出战成员不能另去探索。防守存档不占用真实个体。
- 伙伴档案可设置最多12字昵称，支持清除；昵称独立保存并在进化后保留。收藏、编队和选人同时展示昵称、物种及个体编号，方便区分同种个体。
- 档案按身份、携带物、努力值、招式和进化独立分区。努力值分配就近显示账号储备、个体已分配/总量剩余与单项上限；零储备禁用分配。探索地区使用带解锁状态和野生伙伴预览的主题卡片。
- 进化成功后播放约3秒粒子聚光与新形态揭晓，支持跳过和减少动态效果；失败不播放，刷新不重播，退出清理。演出只负责视觉，形态与资源仍以服务端保存结果为准。
- 探索、岗位、双亲与孵化主理人使用方块选人，展示图片、等级、性别、体力及占用。点击加入/移除，支持已选区逐个移除、清空与按昵称/物种/编号搜索；满员及其它活动占用会明确限制。选择草稿跨页面重绘和状态刷新保留，整页重载恢复已保存数据。
- 探索补给固定6格，每格最多99件，同种道具可占多格。出发前在探索页或从仓库选道具装包，开始探索才从仓库扣取；途中只用随身补给并可查看余量，不能远程补给。结束后余料归库，掉落直接入仓。旧存档正在探索时按空包继续，结束后再按新规则装包。
- 原背包已明确为仓库，与百货公司分签；仓库支持回复道具、携带物、进化石及技能机按用途操作。技能机从229种朱紫本体/DLC索引校验9M兼容，消耗一份进入已掌握招式，不自动覆盖当前四招。联调商店开放3种样例，其余可用测试指令获得。
- 招式选择和技能机学习共享资料面板，展示属性、类别、威力/特殊计算、命中判定、基础PP、优先度、作用目标、招式标记及结构化效果。复杂特殊判定的完整中文说明仍需后续整理，战斗继续执行固定引擎规则。
- 心愿单支持全国图鉴编号精确搜索、中文名字模糊搜索、图文卡片添加/移除、防重复和批量保存；目录覆盖1025种，地图开放内容仍由地区配置决定。
- 玩家界面、性格/特性/招式/道具/属性、状态、操作日志与战报使用中文；名称来自本地原作CSV，内部标识和引擎计算不变，玩家输入的名称/战术保留原文。
- 购买、出售、装备持物、努力值分配、招式调整和等级/进化石手动进化；事务扣发、命令回执防重复和资源账本。商店分探索与重要道具，后者按账号游戏时间每小时限购刷新。
- 地区探索、日夜遭遇、捕获心愿单、经验、训练点、少量野外掉落与药品/持物消耗；探索只把HP带到下一场遭遇，PP和异常状态每场重置，不限制挂机时长。捕获和额外回复只消耗探索包；无球仍继续探索。
- 恢复仅作用选定探索队，耗时为 `ceil(1200 × 总缺失HP / 总HP)` 秒；满血不等待，半血10分钟，全倒下20分钟。恢复后继续原路线，重复申请不延长时间，改编队不更换已开始恢复的成员。
- 产业建设、岗位、边际递减产出、出售和扩建；果园种植、周期结果、有限缓存和收获；两个模块可与探索并行。
- 双亲独占产蛋、整盒孵化、主理人开孵时固定、特性加速、随机遗传与兼容技能传承；完成仅生成一次伙伴。配对结束后双亲解除占用。
- 玩家活动只保存完成时间/游标，查询或操作时事务补结算；每批探索最多120次事件，由 H5 自动继续申请，没有逐玩家后端倒计时。稀有时段按遭遇时间判定。
- 测试页支持1–1000倍挂机变速，探索、恢复、产业、果园、产蛋、孵化及个人商店刷新共用后端游戏时钟；倍率按账号保存，离线继续生效，切换倍率不重算过去的进度。
- 八大道馆串行受理、开战随机 NPC 完整预设、真实六只双打、获胜接任、不可变防守快照、挑战与防守两方各自可见战报及日志；跨季只刷新席位。
- 道馆战报按本人挑战/防守身份显示胜负，列表和详情使用同一结果文案；当前馆主与其他玩家防守存档明确标注。过期比赛仅记录结算失效，不再产生正常席位变更的误导日志。
- 六只全部参战、两只同时在场、实际等级、无赛前对方名单。
- 第九世代机制与 Mega 组合；极巨化、太晶化、Z 招式关闭。旧世代物种和 Mega 道具采用显式 Past 来源兼容，不声称这是朱紫原生赛制。
- 两套 NPC 完整预设开战时随机选择并固定；当前固定策略不分析预设战术文本。
- 道具、特性、持续条件共用 EffectDefinition 基类，从 JSON 反序列化；已导出 1,066 条技术效果索引，不等于全部作为游戏开放内容。
- 原版处理默认继承；已有两个可配置处理器验证真实回复比例和攻击倍率。新行为需要相应处理器，JSON 不执行任意代码。
- 后台高级战斗有并发上限；账号战斗的私有输入与完整结果存于 SQLite，接口仅供参战本人读取本方事件。原战斗实验页在 [battle-lab](http://127.0.0.1:8787/battle-lab/)，不提供账号比赛的匿名查询。

## 测试指令

左侧「测试指令」提供输入框、示例按钮和执行回显。必须以 `--test-mode` 启动；普通启动时后端也会拒绝，不能靠改页面启用。

```text
/资源 金钱 100000
/资源 精灵球 100
/资源 木材 1000
/资源 矿石 1000
/资源 训练点 1000
/资源 技能机007 1
/资源 技能机125 1
/加速 8小时
/加速 7天
/变速 2
/变速 1000
/变速 1
/伙伴 熔岩蜗牛 40
/等级 全体 100
/恢复
/赛季 下一季
/帮助
```

测试页使用中文指令；旧 `/grant`、`/time`、`/pokemon`、`/level all`、`/heal`、`/season next`、`/help` 保持兼容，变速也可用 `/speed`。中文资源/物种名称会映射到原内部标识，时长支持秒/分钟/小时/天。加速单次最多30天，只影响当前账号，不修改真实会话有效期或比赛胜负；切季是全服操作，有进行中比赛时拒绝。

「挂机变速齿轮」可输入1–1000整数或选择快捷档，1倍恢复正常速度。它持续改变当前账号的游戏时间流速；`/加速` 则一次性推进游戏时间，不改变当前倍率。倍率在测试模式重启后保留，普通模式启动时恢复1倍并保留截至启动时已累积的进度；即使探索仍在补结算，也可直接降低倍率。

统一入口为 `src/game/clock.ts` 的 `GameClock`：读取游戏时间、切换倍率、手动推进、换算现实剩余时长。各挂机模块只读取这个时钟并比较原有游标/截止时间，无须分别乘倍率。状态接口返回 `clock: {realTime, gameTime, rate}`；H5只推算显示，资产仍由后端结算。

建议先用默认六只伙伴测试自然探索；再增加资金、加速1小时测试产蛋和产业，开始孵化后继续加速。测试道馆可用 `/等级 全体 100` 与 `/恢复`，结束出战成员的探索/岗位后，在伙伴页选择六人预设并进入备战，再去挑战。取消备战后可重新安排工作。其中两只异性伊布用于测试配对，初始礼包不代表最终方案。

探索前先在「出发前装包」装入球和回复道具；只在仓库备货不会参与探索消耗。技能机可在仓库点「学习招式」，用方块选适用的空闲伙伴，确认后再到档案配置招式槽。机器编号按朱紫本体/DLC解释，内部资源键为 `tm9_001` 等，避免和其他世代同编号混用。重建机器索引可运行 `python scripts/export-machines.py`，原始CSV不改动。

## 本轮范围和测试配置

`config/gameplay.test.json` 集中保存本轮用于联调的初始资产、商品样例、地区、时长、产率、费用与奖励。捕获概率、经验倍率、果树周期和遗传技能扩展属于本作测试规则，不能当作原版公式或最终平衡。暂未校准「六只5级到100级约8–9天」的目标；当前加速用于验证流程。

战术文本会保存并随道馆报名固定，实际仍由固定策略执行，AI 分析尚未接入。联赛、玩家交换、完整技能机获取/制作、特殊条件进化、全服自动赛程留在后续模块；本轮没有把它们伪装成已完成的入口。普通探索真实消耗持物，高级比赛只改变战斗快照。

## 修改效果

`config/effect-catalog.json` 从目标引擎解析后的数据生成，作为完整技术索引；不要把它与 PokéAPI 的道具总数混为一谈。

在 `config/battle-effects.json` 的 effects 中为 canonical engineId 增加或修改覆盖。两类示例：

```json
{"kind":"item","engineId":"leftovers","handler":"residual-heal","parameters":{"numerator":1,"denominator":16}}
```

```json
{"kind":"ability","engineId":"hugepower","handler":"attack-multiplier","parameters":{"numerator":2,"denominator":1}}
```

这些默认值沿用当前基础机制。修改时增加 revision，再重启后端发布；旧版本完整配置保存在 `.runtime/battles/rules/`。同 revision 不允许不同内容，worker 会拒绝执行与服务端启动配置不一致的规则或 NPC 预设。

无形拳等跨游戏版本的变化可能不仅是数值变化，还涉及触发路径；当前保持 gen9 实现，不静默混入 Champions 改动。可以通过新处理器或新的引擎/mod 版本发布该变化。

## 检查

```powershell
node --test tests/*.test.ts
node node_modules/typescript/bin/tsc --noEmit
```

测试覆盖真实引擎效果、版本隔离、Mega、实际等级、隐藏名单、持久化与账号权限、幂等资源操作、离线一次/分次等价、持物消耗与探索PP/异常重置、按缺失HP恢复、并行活动、道馆接任/防守/赛季、八馆两套 NPC 合法性及配置发布。浏览器已走通注册、建厂、探索、产蛋/孵化、种植/收获、加速、购买、真实道馆胜利和重新登录；同页及跨标签页切换账号会清理旧战报。

变速测试覆盖2倍1小时与1倍2小时的多模块结果等价、倍率切换连续性、离线及重启持久化、账号隔离、真实会话有效期、普通模式恢复1倍，以及补结算期间降低倍率。

补给测试覆盖6/99边界、同种多格库存合计、失败回滚、重复取还、重启、空包迁移、仓库隔离、药品消耗、球优先级、满包掉落入仓及账本不伪增。技能机测试覆盖原版兼容、归属、占用、重复学习、失败不扣与不覆盖四招，HTTP与真实H5均走通学习和装包归还。

原 11 页纯视觉 Demo 保持在 `demo/visual/`；功能 H5 位于 `web/game/`，原战斗实验页位于 `web/battle-lab/`。正式待定参数继续保留在数据账本，本轮测试参数单独管理。

功能 H5 使用红白像素主题；新生成的32个模块/道具图标与村庄场景已保存于 `web/game/art/`，图标通过CSS atlas定位使用。素材、提示词和生成方式见 [美术记录](web/game/art/README.md)。
