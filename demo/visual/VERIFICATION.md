## 验证限制

离线入口采用普通 script、相对路径与本地 PNG，不依赖 fetch、ES Module 或远程素材。实际 `file://` 自动化验证未完成：浏览器工具禁止该协议，原生 Chrome 无头尝试因当前环境的 GPU 子进程错误退出。本次浏览器通过结论适用于已实测的本地 HTTP 入口；离线入口不标记为已通过真实浏览器运行验证。

全部数值、人物搭档、奖励、赛程和战报用于视觉示意，不验证其游戏平衡或原作合法性。
