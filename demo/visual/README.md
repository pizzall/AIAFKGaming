# 宝可梦挂机 H5 视觉 Demo

设计画布：1920×1080；风格：GBA／DS 时代的经典像素界面，红白主色；范围：11 个玩家页面。

双击 [index.html](index.html) 即可打开。使用左侧导航查看游戏页面；画布外的顶部控制栏用于直接切换页面和静态状态。浏览器窗口改变时，整张画布等比缩放。

| 联机广场 | 公开交换、我的挂单、历史记录与交换确认 |

## 视觉边界

所有等级、价格、库存、计时、产量、成长目标、奖励、战报和赛程都是固定版式样例，不代表最终游戏配置。页面交互只改变展示页面、页签、选中卡片、弹窗和临时文本。

不运行探索、捕获、战斗、训练、孵化、生产、购买或交换结算；不调用 AI，不连接数据库，不保存玩家资产，不随机生成奖励。倒计时不会随真实时间递减。文本输入不会写入实际战术配置；刷新后回到示例。

设施与果树使用通用像素示意位图，各树种由名称和生长阶段区分。NPC 使用代表搭档和姓名展示，实际赛季队伍以后续配置为准。

百货公司中的“重要道具”指进化道具、携带物与技能机。两类货架各展示 8 件固定商品样例，价格与上架内容均不作为最终配置。礼包放在独立页签。商品沿用通用球、背包与徽章示意图，尚未接入逐件道具图标。道具与树果的本地数据核查见 [覆盖说明](../../docs/item-berry-coverage.md)。

界面以红色导航、白色面板和浅玫瑰色选中态为主，稀有奖励保留少量金色。宝可梦、属性标签和场景保留自然配色；`mint.png` 沿用已有文件名，当前为浅玫瑰色面板皮肤。

## 借用的方法论

方法来源：`D:/workspace/FigmaPlan/Frameforgelight/titanfoundry/skills/frameforge-demo/`。

采用固定逻辑画布、组件复用、页面/状态清单、独立可替换位图、素材来源记录和浏览器视觉检查。保留普通文字与边框，视觉素材使用 PNG；没有 SVG、Canvas 绘画或图标字体。

本次交付适配为本项目的纯 H5 视觉样稿。`project.json` 是页面与素材清单，未冒充 Frameforge 的 Unity 节点导出契约；没有生成 Unity Prefab、布局编辑器或真实游戏流程。公共按钮、面板和成员卡在本 Demo 的展示组件内统一复用。

## 文件

- `index.html`：离线入口与公共外框。
- `styles.css`：布局、等比适配、面板、按钮及像素图显示。
- `app.js`：11 页的固定视图、页签和弹窗。
- `pokemon-data.js`：从本地索引抽取的 74 条展示资料，不含结算数据。
- `project.json`：页面、画布、素材 ID、路径及来源类别。
- `assets/pokemon/`：复制进包的本地正面/背面图，不修改原素材。
- `assets/icons/`、`assets/scenes/`：使用内置 ImageGen 生成的通用图标、产业/果树示意图与路线背景。
- `assets/ui/`：独立的纯色 PNG 面板皮肤，普通底色不需要重画复杂美术。
- [ASSET-PROMPTS.md](ASSET-PROMPTS.md)：生成方式、完整提示词与素材路径。
- `screenshots/`：浏览器视觉检查截图。

替换素材时保持其路径，或同步修改 `project.json` 和使用处的引用。PNG 原图保留透明通道和原始比例，宝可梦图采用最近邻缩放。

如需通过本地 HTTP 查看，可在项目根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

随后打开 `http://127.0.0.1:8765/demo/visual/index.html`。服务仅用于预览，不提供写入或业务接口。
